Privacy policy

Effective date: 23 October 2026

This policy describes CloudPool, the owner's private file gateway using rclone hosted on Blitz.cloud with Google Drive. The owner accesses the gateway through a password-protected web interface on Windows or Android. It is a personal-use setup.

Information accessed

The gateway processes Google authorization credentials, file and folder names, file metadata, storage usage information, and file contents when needed for the operations the owner requests. Access is limited to the Google accounts the owner authorizes. The gateway also processes the owner's sign-in credentials and ordinary connection information needed to provide authenticated access.

Purpose of access

Google Drive data is used to list, open, upload, download, organize, rename, move and delete the owner's files, and to present selected storage folders together through an rclone Union configuration. The Google Drive scope permits file management across the authorized account; the gateway configuration determines the folders used by the pool.

Where information is stored

Cloud files are stored in the connected Google Drive accounts. Uploads, downloads, file metadata and other requested file operations pass through the gateway hosted on Blitz.cloud. Transfers may create temporary buffers or caches on the gateway, and downloaded or opened files may be stored on the owner's devices.

The gateway's rclone configuration and Google authorization tokens are maintained in private application settings and persistent application storage on Blitz.cloud. The hosting provider processes the gateway's network traffic, application settings, stored configuration and operational logs to run the service. Local rclone or RSAF clients, when used, maintain their own configuration and caches on the owner's devices.

Sharing and advertising

This personal setup does not sell Google user data or use it for advertising. Google processes data as the authorization and storage provider. Blitz.cloud processes data as the gateway's hosting provider, and the owner's browser and any other chosen clients process files during use. Any additional sharing with another recipient is initiated by the owner.

Retention, deletion and revocation

Files remain in their Google Drive accounts until the owner deletes them, subject to Google's storage and trash policies. Stored authorization credentials remain until revoked or removed from the relevant configuration and application settings. Copies, caches and operational logs are retained according to the clients' and hosting provider's settings. Removing a connection does not itself delete cloud files.

The owner can revoke authorization through Google Account connections, then remove the corresponding hosted and local configuration, imported credentials and any unwanted copies. Revoking authorization prevents future authorized access; it does not erase existing downloads.

Use of this website

These public information pages are hosted on GitHub Pages and are separate from the gateway on Blitz.cloud. They contain no sign-in form, file upload form, advertising or analytics scripts, and do not connect to the Google Drive API. GitHub may process ordinary connection information, such as IP addresses and request logs, under its own privacy practices.

Google API data use

CloudPool's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and updates

For questions, use the support email listed on this project's Google authorization screen. Changes to this policy will be reflected on this page with an updated effective date.
