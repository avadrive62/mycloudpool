Privacy policy

Effective date: 17 October 2026

This policy describes MyCloudPool, the owner's personal file management setup using rclone on Windows and RSAF on Android with Google Drive. The project is not offered as a public service.

Information accessed

The clients use Google authorization credentials, file and folder names, file metadata, storage usage information, and file contents when needed for the operations the owner requests. Access is limited to the Google accounts the owner authorizes.

Purpose of access

Google Drive data is used to list, open, upload, download, organize, rename, move and delete the owner's files, and to present selected storage folders together through an rclone Union configuration. The Google Drive scope permits file management across the authorized account; the local configuration determines the folders used.

Where information is stored

Cloud files are stored in the connected Google Drive accounts. Downloads, opened files, edits and temporary caches may be stored on the owner's devices. Authorization credentials are maintained in the clients' local configuration. RSAF manages its imported configuration within the Android app's storage.

MyCloudPool operates no separate server that receives Google Drive content or authorization credentials. This informational website does not connect to the Google Drive API.

Sharing and advertising

This personal setup does not sell Google user data or use it for advertising. Data is processed by Google as the storage provider and by the clients and applications the owner chooses to use with the files. Any sharing or transfer to another recipient is initiated by the owner.

Retention, deletion and revocation

Files remain in their Google Drive accounts until the owner deletes them, subject to Google's storage and trash policies. Local copies and caches remain until removed by the client or owner. Removing a connection does not itself delete cloud files.

The owner can revoke authorization through Google Account connections, then remove the corresponding local configuration and any unwanted local copies. Revoking authorization prevents future authorized access; it does not erase existing downloads.

Use of this website

These information pages contain no sign-in form, file upload form, advertising or analytics scripts. The website hosting provider may process ordinary connection information, such as IP addresses and request logs, under its own privacy practices.

Google API data use

MyCloudPool's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and updates

For questions, use the support email listed on this project's Google authorization screen. Changes to this policy will be reflected on this page with an updated effective date.
