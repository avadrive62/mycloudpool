CloudPoolPrivacy policy

Personal file management

One place to work with my cloud files.

CloudPool is a private file gateway that runs rclone on Blitz.cloud. The owner uses it to manage their authorized Google Drive accounts from a web browser on Windows or Android.

It is for the owner's personal use. It is not offered as a public storage or account-registration service.

What the setup does

  • Lists and opens files and folders in the accounts the owner authorizes.
  • Uploads, downloads, organizes, renames and deletes files at the owner's direction.
  • Presents selected folders together through an rclone Union configuration and places new files according to its storage rule.

Each Google account retains its own ownership, permissions and storage quota. This project does not increase an account's Google Drive quota.

Access to Google Drive

The owner authorizes each Google account using their own Google Cloud OAuth configuration. The file-management scope allows the gateway to list, upload, download, organize and delete files at the owner's request. The configured pool presents selected folders together.

The gateway keeps its rclone configuration and Google authorization credentials in private application settings and persistent storage on Blitz.cloud. File contents and metadata pass through the gateway during requested operations. Files are stored in the connected Google Drive accounts; transfers may also create temporary buffers, caches or downloaded copies.

These public information pages are hosted on GitHub Pages. They explain the separate, password-protected gateway and its privacy practices. The information pages contain no sign-in or upload form and do not receive Google Drive files or credentials.

Privacy and control

Read the CloudPool privacy policy for the data used by this setup, storage practices and how to revoke access.
